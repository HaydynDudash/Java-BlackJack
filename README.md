# Java Blackjack

## Overview
A console-based Blackjack game developed in Java using object-oriented programming.

## Features
- 52-card deck with four suits
- Deck shuffling
- Player and dealer gameplay
- Blackjack hand-value calculation
- Ace value adjustment
- Betting and player balances
- Multiple players
- Hit and stay gameplay
- Dealer turn and scoring

## Object-Oriented Concepts
- Classes and objects
- Encapsulation
- Inheritance
- ArrayLists
- Constructors
- Getters and setters
- Methods

## Technologies
- Java
- IntelliJ IDEA
- JDK 24
