# Java Blackjack

## Overview

A console-based Blackjack game developed in Java using object-oriented programming.

## Features

- 52-card deck with four suits
- Deck shuffling
- Player and dealer gameplay
- Blackjack hand-value calculation
- Automatic Ace value adjustment
- Player betting and balance tracking
- Multiple players
- Hit and stay gameplay
- Dealer gameplay and scoring
- Players can choose whether to play each round

## Object-Oriented Concepts

- Classes and objects
- Constructors
- Getters and setters
- ArrayLists
- Encapsulation
- Methods

## Technologies

- Java
- JDK 24
- IntelliJ IDEA

## Project Structure

- `Main.java` — Controls the main game flow
- `Cards.java` — Represents individual playing cards
- `Deck.java` — Creates and manages the deck and shuffling
- `Hand.java` — Stores and manages cards in a hand
- `Player.java` — Stores player information and gameplay data
- `Dealer.java` — Handles dealer gameplay and dealing
- `Casino.java` — Manages players and game rounds
